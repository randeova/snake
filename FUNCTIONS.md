# main.cpp 用到的所有函数 —— 来源对照表


它们来自四层：C++ 标准库、Windows 操作系统、编译器扩展、以及你自己的文件。

## 1. 自己的函数（只有 5 个）

| 函数               | 职责  | 一句话说明                               |
| ---------------- | --- | ----------------------------------- |
| `cellAt(x, y)`   | 画一格 | 这一格该显示食物 `*`、蛇头 `H`、蛇身 `o` 还是空地 `.` |
| `render()`       | 拼整帧 | 把整个棋盘（含分数行）拼成一个字符串，一次性输出            |
| `spawnFood()`    | 放食物 | 遍历所有格子，收集空格，随机挑一个                   |

| `isDeadly(head)` | 判死  | 这一格是撞墙还是撞自己                         |

**这 5 个函数就是项目里真正"属于我"的逻辑。** 剩下全是站在别人肩膀上。

## 2. C++ 标准库 · `std::vector`（容器）

`g_snake`、`freeCells` 都是 `std::vector<...>`，下面这些是**它自带的成员函数**。

| 成员函数               | 语义          | 复杂度                      | 代码里用在哪                                              |
| ------------------ | ----------- | ------------------------ | --------------------------------------------------- |
| `size()`           | 有几个元素       | **O(1)**（两个指针相减）         | `g_snake.size()` 判死循环、`freeCells.size()` 取随机下标      |
| `operator[]`       | 取第 i 个元素    | **O(1)**                 | `g_snake[0]`（蛇头）、`g_snake[i]`、`freeCells[rand()%n]` |
| `insert(pos, val)` | 在 pos 处插入一个 | **O(n)** ← 要把后面全往后挪      | `g_snake.insert(g_snake.begin(), head)` 头进          |
| `pop_back()`       | 删掉最后一个      | **O(1)**（就是 `--_Mylast`） | 尾出（没吃到食物时）                                          |
| `push_back(val)`   | 在末尾加一个      | 平摊 **O(1)**              | `freeCells.push_back({x, y})`                       |
| `empty()`          | 是不是空的       | **O(1)**                 | `freeCells.empty()` 判"棋盘被占满"                        |
| `reserve(n)`       | 预留 n 个位置    | **O(n)**                 | `freeCells.reserve(kWidth * kHeight)` 避免反复扩容        |
| `begin()`          | 指向开头的迭代器    | **O(1)**                 | `g_snake.begin()` 作为 insert 的插入位置                   |

### 内部就三个指针（知道这个，上面全懂了）

```
_Myfirst                _Mylast              _Myend
   ↓                       ↓                    ↓
  ┌───┬───┬───┬───┬───┬───┬───┬───┬───┐
  │ A │ B │ C │ D │   │   │   │   │   │
  └───┴───┴───┴───┴───┴───┴───┴───┴───┘
  └────── 已使用 size=4 ─────┘└─ 预留容量 ─┘
```

- `size()` = `_Mylast - _Myfirst`
- `pop_back()` = `--_Mylast`（**不释放内存**）
- `insert(begin(), ...)` = 把所有元素**整体往后挪一格** ← 这就是它慢的原因

## 3. C++ 标准库 · `std::pair`

`std::pair<int,int>` 是"装两个东西的盒子"。

| 名字        | 是函数吗        | 说明                                       |
| --------- | ----------- | ---------------------------------------- |
| `.first`  | ❌ **是成员变量** | 第一个值（我们约定是 x）                            |
| `.second` | ❌ **是成员变量** | 第二个值（我们约定是 y）                            |
| `==`      | ✅ 运算符       | `g_snake[i] == head` 逐个比较 first 和 second |
| `<` `>` 等 | ✅ 运算符       | 先比 first，first 相同再比 second（本项目没用到）       |

> `pair` 的源码大概就是：`struct pair { T1 first; T2 second; ... };` —— 它真的没什么魔法。

## 4. C++ 标准库 · 其他

| 名字                   | 来自哪个头文件      | 干什么               | 代码里用在哪                                |
| -------------------- | ------------ | ----------------- | ------------------------------------- |
| `std::cout`          | `<iostream>` | 标准输出流对象           | `std::cout << "\033[H" << render();`  |
| `operator<<`         | `<iostream>` | 往流里塞东西            | 同上                                    |

| `std::string`        | `<string>`   | 可变长字符串            | `render()` 里的 `buf`                   |
| `string::operator+=` | `<string>`   | 往字符串末尾追加          | `buf += cellAt(x, y);`                |
| `string::reserve(n)` | `<string>`   | 预留容量              | `buf.reserve(...)`                    |
| `std::to_string(n)`  | `<string>`   | 数字 → 字符串          | `"Score: " + std::to_string(g_score)` |

| `srand(seed)`        | `<cstdlib>`  | 设定随机数种子（**只调一次**） | `srand((unsigned)time(nullptr))`      |

## 5. Windows 操作系统 API（`<windows.h>`）

| 名字                                   | 是什么 | 干什么                | 代码里用在哪                            |
| ------------------------------------ | --- | ------------------ | --------------------------------- |
| `HANDLE`                             | 类型  | 句柄（"某个系统资源的编号"）    | 接收 `GetStdHandle` 的返回值            |
| `DWORD`                              | 类型  | 32 位无符号整数          | `lastMove`、`mode`                 |
| `GetStdHandle(...)`                  | 函数  | 拿到标准输入/输出的句柄       | `GetStdHandle(STD_OUTPUT_HANDLE)` |
| `STD_OUTPUT_HANDLE`                  | 宏常量 | "标准输出" 的编号         | 同上                                |
| `GetConsoleMode(h, &m)`              | 函数  | 读当前控制台的模式          | 开 ANSI 之前先读                       |
| `SetConsoleMode(h, m)`               | 函数  | 设置控制台模式            | 打开 VT 转义序列支持                      |
| `ENABLE_VIRTUAL_TERMINAL_PROCESSING` | 宏常量 | "允许 ANSI 转义序列"这个开关 | `mode \| ENABLE_...`              |
| `GetTickCount()`                     | 函数  | 开机到现在的毫秒数          | 计时：每 300ms 走一步                    |

> 这些函数**只有 Windows 有**。想跨平台得换成 `std::chrono`（标准 C++）。

## 6. 编译器扩展（`<conio.h>`）

| 名字         | 干什么        | 关键特性                      |
| ---------- | ---------- | ------------------------- |
| `_kbhit()` | 问："有键在等吗？" | **不等人**（非阻塞），有就返回非 0      |
| `_getch()` | 取一个键       | **不等回车**、**不回显**，返回 `int` |

> 严格说 `conio.h` **不属于 C++ 标准**，是编译器厂商提供的。
> 标准 C++ **没有**"不等回车读键盘"的能力 —— 所以控制台游戏都得借它。

## 8. 反向速查：我想干什么 → 用哪个

| 我想要       | 写法                                                          |
| --------- | ----------------------------------------------------------- |
| 蛇现在几节     | `g_snake.size()`                                            |
| 蛇头的 x / y | `g_snake[0].first` / `g_snake[0].second`                    |
| 第 i 节身子   | `g_snake[i]`                                                |
| 让蛇变长一节    | `g_snake.insert(g_snake.begin(), head)` 且**不** `pop_back()` |
| 让蛇保持长度    | `insert` 之后 `pop_back()`                                    |
| 这一格有没有蛇   | 遍历 `g_snake` 比较坐标                                           |
| 随机一个格子    | `rand() % n`                                                |
| 随机但不落在蛇身上 | 先收集空格（`freeCells`），再 `rand() % freeCells.size()`            |
| 数字转字符串    | `std::to_string(n)`                                         |
| 清屏        | `system("cls")`（慢、会闪）或 `"\033[H"`（快、不闪）                     |
| 让程序等一会儿   | `Sleep(300)`（毫秒）或 `std::this_thread::sleep_for`             |
| 知道过了多少毫秒  | `GetTickCount()`                                            |
| 读键盘但不卡住   | `_kbhit()` + `_getch()`                                     |
