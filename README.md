# 贪吃蛇（C++ 控制台版）

用 C++ 从零实现的经典贪吃蛇，跑在 Windows 控制台里。
这是我从零学习 C++ 项目开发的练手项目。

## 演示

![游戏截图](screenshot.png)

## 怎么运行

需要：Windows + Visual Studio 2022（自带 MSVC 和 CMake）

最简单的方式：**双击项目根目录下的 `build.cmd`**。

或者手动执行：

```
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Debug
build\Debug\snake.exe
```

## 操作

| 按键 | 作用 |
|:---:|---|
| `W` / `A` / `S` / `D` | 上 / 左 / 下 / 右 |
| `Q` | 退出 |

> ⚠️ 需要在**英文输入法**下按键，中文输入法下按键无效。

- 吃到一个食物 **+10 分**，蛇身变长 1 节
- 撞到墙壁或自己的身体 → 游戏结束
- 蛇每 300 毫秒前进一格

## 项目结构

将一大串 `main` 代码拆分成多个文件：`.hpp` 作函数声明，`.cpp` 作函数具体实现。

- `include/snake/game.hpp`：游戏数据与规则声明，棋盘尺寸、方向、蛇 / 食物 / 分数等状态
- `include/snake/render.hpp`：画面相关的内容，以及怎么让画面不闪动的声明
- `include/snake/input.hpp`：接收键盘的函数声明
- `src/game.cpp`：游戏规则，生成食物、计算新蛇头、碰撞判定、蛇的身子变长
- `src/render.cpp`：把游戏状态渲染成字符画面，整帧一次性输出
- `src/input.cpp`：把按键翻译成想走的方向
- `src/main.cpp`：主循环，把以上各个部分按顺序串起来
- `FUNCTIONS.md`：项目中用到的所有函数来源清单（标准库 / Windows API / 自己实现）

## 实现要点

**1. 固定时间步长的主循环**

主循环一直在转，但只有距离上次移动超过 300 毫秒时才推进一格。
这样**游戏速度与机器性能无关**——不会出现"在快电脑上快得没法玩"的情况。

**2. "头进尾出"的移动方式**

每步在蛇头位置插入新的一节，再删掉尾巴。
**吃到食物时跳过"删尾巴"这一步**，长度因此 +1——这就是"变长"的全部秘密。

**3. 禁止 180° 掉头**

用两个变量区分「正在走的方向」和「玩家想走的方向」：
按键只修改后者，且当它与前者相反时拒绝。
这样即使在同一帧内连按两个方向，蛇也不会一头撞进自己的脖子。

**4. 食物永远不会长在蛇身上**

生成食物时，先遍历整个棋盘收集**所有空格**，再从中随机挑一个；
而不是"随机抽一格、撞到蛇就重抽"——后者在蛇很长时循环次数不可控。

**5. 无闪烁的画面刷新**

不调用清屏，而是把光标移回左上角后用整帧覆盖，
配合控制台的 ANSI 转义序列，画面稳定不闪。

## 用到的技术

- C++20、CMake
- 多文件工程（声明与实现分离）
- 控制台 ANSI 转义序列（光标控制、无闪烁刷新）
- 固定时间步长的主循环

## 开发过程

这个项目按阶段推进，每个阶段只增加一个功能：

```
静态画面 → 主循环 → 键盘控制 → 食物与计分 → 拆分多文件 → 发布到 GitHub
```

最初的版本是一个 269 行的单文件，后来按职责拆分成了现在的 7 个文件。
